# EP001 分镜（节选 4 镜）

> 工艺要点：建立镜头自增（剧本没写也必须有）；五连接词时序链（首先/接着/随后/
> 与此同时/最终）；动作量化；每镜必有叙事动机句；静止顶点 + 反应特写。
> 规则见 `skills/short-drama-storyboard/references/production-shot-grammar.md`。

## 1-1 建立镜头（剧本未写，分镜自增）

- 纲要：酒店门前全貌，沈一舟拎箱走向红毯，赵经理在门前候位。

```text
真人电影风格,首先镜头从高处俯瞰全景静止约0.5秒展示酒店旋转门与红毯全貌；接着
缓慢向下推近同时向画面中央微移；随后聚焦于红毯北端拎着保温箱走来的沈一舟与
门前站定的赵经理之间的纵深轴线；与此同时旋转门匀速转动玻璃反光缓慢扫过红毯；
最终镜头稳定在中全景位置，两人相距约五米。镜头运动：从高角度全景缓慢推近至
中全景，叙事动机为建立空间关系后引导观众聚焦即将发生的拦截。
```

## 1-4 对峙升级（丢餐盒）

- 纲要：赵经理掀盖抓餐盒丢上红毯，汤汁洇开。

```text
真人电影风格,首先赵经理右手一把掀开保温箱顶盖魔术贴发出撕啦声；接着抓出一盒
餐食在手中掂了两下幅度约10厘米；随后手腕一翻将餐盒随手丢向红毯；与此同时
沈一舟拎箱的左手指节收紧箱体轻微下沉；最终餐盒摔开汤汁在红毯上洇出深色一片，
赵经理拍了拍手指。镜头运动：中景固定镜头保持不动，叙事动机为以静制动让羞辱
动作的全过程完整落在观众眼里。
```

## 1-7 静止顶点（秘书递工牌）

- 纲要：领队秘书双手递上工牌深躬，全场声音抽空。

```text
真人电影风格,首先领队秘书双手托着烫金工牌自画面右侧入画停在沈一舟胸前约20
厘米处；接着上身前倾约30度深深躬身保持静止；随后沈一舟视线从红毯上的餐盒
缓缓抬起落在工牌上；与此同时背景中赵经理的手指僵在半空旋转门恰好停转；最终
画面在工牌特写与两人一立一躬的构图上静止约1秒 说：沈董，集团年会审议名单已
备好，就等您签字。镜头运动：缓慢推近至近景后完全静止，叙事动机为以绝对静止
让身份揭晓的信息完全落下。
```

## 1-8 反应合唱（三连惊叹第一镜）

- 纲要：服务员甲托盘一斜，难以置信。

```text
真人电影风格,首先服务员甲手中的银色托盘向右倾斜约15度杯子沿盘面滑出半寸；
接着她左手慌忙扶住杯身指尖发抖；随后双眼瞪大视线在沈一舟与工牌之间来回移动
两次；与此同时身后另一名服务员停下脚步探头张望；最终服务员甲嘴唇微张保持
失神姿态 说：沈……沈董？镜头运动：快速甩镜从主轴线切至服务员甲近景，叙事
动机为以快速运动承接全场注意力的第一次转移。
```

---

自检记录：4 镜均有"首先…最终"起止闭环、"与此同时"并行微动态、量化幅度与
叙事动机句；台词 ≤1 句/镜；1-7 静止顶点后紧跟 1-8 反应特写（反应镜头预算）。
