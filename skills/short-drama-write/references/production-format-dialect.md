# 生产通行剧本方言

真实短剧生产中最常见的剧本书写方言，源自大规模生产数据的格式统计，示例为合成
改写。本套件的规范格式见 [screenplay-format.md](screenplay-format.md)；本文档
服务两个场景：

1. **规范化入口**：创作者交来的现成剧本多用此方言，识别它能显著减少
   "非规范文本 → 规范化预览" 的误映射；
2. **交付偏好**：创作者要求按行业习惯交付时，可作为 `taste_option` 输出方言。

方言与规范格式仅是表层语法差异，因果、场景功能与所有权纪律不变。

## 场头与人物行

```text
46-1 夜 内 无间岛地下密道
人物：萧廷烨、苏青黛、老国公
```

- `集-场` 编号（`46-1`）、时段（日/夜）、内外（内/外）、地点；要素恒定，顺序有变体
  （亦见 `场景：地点 日，外` 与 `场：1-1` 独立行式）。
- 人物行列出本场出镜者；龙套功能化命名（车手甲、长老A、弟子1），主角用 2–3 字
  有记忆点的名字。

## 行内标记

| 标记 | 含义 | 对应规范标签 |
|---|---|---|
| `△`（约半数剧本）/ `▲` | 动作行前缀 | 普通动作段落 |
| `角色（情绪/动作）：台词` | 台词行 | `角色（可表演提示）：台词` |
| `角色OS：` / `（OS）` | 心声 | `[OS]` |
| `角色VO：` / `V.O` | 画外音 | `[VO]` |
| `-VO-：雷声`（无角色名） | 纯音效描述 | `[SFX]` |
| `【字幕：无间岛火雷已引爆】` | 屏幕必读文字 | `[画面文字]` |
| `【快闪】…【闪出】` | 闪回段落边界 | `[转场]` + 段落 |
| `【卡点】` / `【结尾钩子】` | 集尾钩子定格点 | 集尾场景 + `[连续性]` 交接 |

规范化时按上表映射；映射不了的自造标记进入 `mapping_review_request`，不要静默
丢弃或猜测语义。

## 表演密度惯例（SCR-08）

- 情绪括号密度极高：几乎每句台词带（委屈）（冷笑）（强装镇定）级别的指令。
  规范化保留原文；新写作时密度是 `taste_option`，但指令必须可表演（SCR-03）。
- 微表演词库取代形容词堆叠：指节泛白、咬肌鼓起、喉结滚动、下颌线绷紧、睫毛
  颤动、眼尾收紧。写"1 毫米级"身体信号，不写"她很愤怒"。
- 台词轮次简短、攻防明确；长解释拆成"逼问—抵抗—让步"的回合。

## 对白攻防回合

生产剧本中的高张力对话遵循可复用的回合结构（合成示例均改写自真实模式）：

- **每轮只做一件事**：逼问、抵赖、加码、让步、反将——一句台词承载一个动作，
  信息量大的解释拆成多轮攻防。
- **打脸三段式**：挑衅方步步加码 → 嚣张顶点（当众宣判/开除/羞辱）→ 一个
  不可辩驳的事实反转（当事人亮底牌、第三方闯入作证、实物证据）。顶点前
  不提前泄底。
- **谈判用条件清单**："我有三个条件"式的逐条报价，每条比前一条更越界，
  对手方逐条失态，是权力反转的标准载体。
- **强弱互换的姿态语言**：强势方台词变短、弱势方台词变长是局势翻转的信号；
  彻底掌控局面的一方用平静短句（"我是在玩你。你能怎么办？"）。
- **旁观者声部**：围观群像（弟子甲、车手乙）用一两句议论放大赌注，不参与
  攻防本身。

## 扩写工作流

生产中存在"原文 → 扩写稿"流程（如 1500 字扩到 3000 字）：扩写只加动作行、
反应镜头与微表演载体，**不加新情节、新信息或新角色**。扩写稿仍以原文为
authority；语义新增属于 owner 修订，不属于扩写。

## 与规范格式的取舍

- 方言优点：生产端熟悉、`△` 行利于逐镜拆解、情绪括号直接喂给分镜表演描述。
- 规范格式优点：场景 ID 稳定可索引、六类生产标签边界清晰、便于跨集引用。
- 同一项目内保持一种正文语法（`structural_invariant`：索引器只解析声明过的语法）；
  跨方言迁移走规范化预览 + 创作者接受，不做静默转换。
