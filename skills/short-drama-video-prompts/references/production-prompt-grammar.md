# 生产视频提示词语法惯例

真实短剧生产中图生视频提示词的通行语法，源自大规模生产数据的模式提炼，示例为
合成改写。本套件的 motion spec 方法见 [motion-recipe.md](motion-recipe.md)；本文档
是生产端语法的对照参考：写 generic prompt 时可借用其成熟约定，但套件产物仍以
motion spec 七部分为权威结构，且**不调用任何生成服务**。

## 全局约束头

每条生产 prompt 以全局约束开头，常见要素：

- 风格声明：真人电影风格 / 真人写实风 / 三维动漫风；
- 禁字幕禁文字（正文与收尾各兜底一次：`【不出现任何文字字幕】`）；
- 声音边界：无 BGM，或"仅音效不要背景音乐"；
- 可选编号要求清单：至少 N 个镜头、禁止描述服装穿着（避免与参考图冲突）、
  写实主义摄影（真实人体比例、皮肤次表面散射、自然光影）、严守 180° 轴线。

对应本套件：这些属于 production profile（`taste_option`，VID-07）；但"一经选定
整卷一致，不逐镜漂移"是 `craft_default`（VID-10），台词冻结与负面清单兜底同属
此项。

## 分镜行语法

```text
c01,3s,(空间:办公室(@图3))(姿态:林某(@图1)-坐在桌前看手机)(位置:林某-办公桌后、
面朝门口)(情绪:林某-凝重 6/10) 近景，缓慢推进。他看到消息后眉头紧锁，指尖
停在屏幕上，喉结滚动一次。背景虚焦。
```

要素拆解：

| 要素 | 约定 |
|---|---|
| `c01,3s` | 镜内片段编号 + 时长；总和≤镜头时长（VID-04） |
| `(空间:X(@图N))` | 场景绑定参考图 |
| `(姿态:角色(@图N)-动作)` | 出镜者逐一绑定参考图 + 起始姿态 |
| `(位置:角色-方位、朝向)` | 空间关系显式化，防越轴 |
| `(情绪:角色-情绪 N/10)` | 情绪强度量化，供表演幅度校准 |
| `背景虚焦` | 注意力控制的高频手段 |

对应本套件：`(@图N)` 即 keyframe/asset binding 的生产形态——绑定已承载外观时，
正文只写"从此刻怎么变"（VID-03 参考帧经济性）。

## 台词绑定三态

| 形态 | 语法 | 用途 |
|---|---|---|
| 口型台词 | `角色（情绪）：台词` 或 `角色用中文冷漠地说道<台词>` | 需要口型匹配 |
| 无口型心声 | `角色无口型用中文内心独白<台词>` | OS，面部不动口型 |
| 台词冻结 | `角色严格按照台词说话，不要增加台词或减少台词` | 防模型自行加词 |

对应本套件：dialogue refs 只读（VID-01）；"防加词"约束是 end report 可核对的
生产兜底，值得写进 generic prompt。

## 灯光与构图词汇

伦勃朗三角光、冷暖光交界线、浅景深散景、前中远景递进、对角线构图、逆光轮廓。
属 `taste_option`，但"光影具象化内心矛盾"（冷暖交界打在犹豫者脸上）是生产端
反复使用的可靠手法。

## 负面清单（成熟兜底项）

无明星脸、无未提及人物入镜、面部稳定不变形、人体结构正常、动作自然不僵硬、
无穿模、无闪烁、无色彩断层、无 Logo/水印/UI 元素。

这些兜底项不替代 motion spec 的结构纪律：一条 prompt 仍只实现一个 editorial
boundary 内的变化，不偷藏切镜（见 SKILL.md 单镜头边界）。
