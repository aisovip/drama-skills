# 生产视频提示词语法：成片层语法、连续性系统与模型适配

提炼自大规模真实短剧生产语料（数十万条视频生成任务），示例均为合成改写。本套件
的 motion spec 方法见 [motion-recipe.md](motion-recipe.md)；本文档是生产端语法的
对照参考：写 generic prompt 时借用其成熟约定，但套件产物仍以 motion spec 七部分
为权威结构，且**不调用任何生成服务、不出现供应商与模型产品名**——模型相关规则
一律写成"按目标模型确认"的条件规则。

核心认知：

1. **视频从静帧起动**：生成起点是分镜首帧图，所以每条 prompt 的动作编舞必须从
   "当前静止状态"出发，收在"明确的终止姿态"。
2. **模型不记得上一镜**：跨镜头一致性完全靠 prompt 显式携带状态。上一镜的结束
   状态逐字成为下一镜的开始状态（CON-01 的生产表述）——整套工艺最核心的连续性
   工程。
3. **指代必须绝对**：禁用代词"他/她/它"，每次都写角色名；禁比喻拟人（"如鹰隼
   般"），一律写**物理成因**（"眼睛变红"→"双眼布满血丝"）。

## 一、两代语法（按目标模型能力选用）

### A 型：单镜六件套（4-8s 短镜模型，表演线）

```text
<风格头>,画面描述: <按时间顺序的动作+拟声词+节奏，从静止状态起手>。
视觉重点：观众视线聚焦于<焦点>。
构图(Composition): <中心构图|三分构图|负空间构图|过肩…>。
景别(Shot Scale): <远景|全景|中景|近景|特写|大特写>。
机位(Camera Position): <正面|侧面|轴线后侧|正上方…>机位。
角度(Angle): <平视|仰拍|俯拍|上帝视角90度俯拍>。
镜头类型(Lens Type): <标准镜头|广角24mm|长焦…>。
光线(Light): <光源+方向+效果>。
【角色状态追踪】<逐角色状态块，见第二节>
```

画面描述带**拟声词和物理量**："右手猛地发力，'锵'一声清脆的剑鸣，长剑完全出鞘"。

### B 型：15s 分镜组（声画同出模型，量产主力）

```text
<风格头>,画面不要出现任何文字，生成视频无BGM；
c01,4s,(空间:<场景资产名+具体位置>)(姿态:<角色>(@图片N)-<姿态>; …)
(位置:<角色>-<相对方位>; …)(情绪:<角色>-<情绪词> <强度>/10)
<景别>，<时序动作+微动态+光线>。<角色>(@图片N)用中文<情绪副词>说道<台词>
c02,3s,(…) …
【不出现任何文字字幕】
```

- 子镜 `c01~c08` 各带秒数，总和≈容器时长（15s 主力）；4-6 个子镜/条；
- **四元组** `(空间:)(姿态:)(位置:)(情绪:N/10)` 置于每个子镜开头——空间锚定 +
  上一子镜终态显式续写；
- `@图片N` 资产引用：N 按 角色→物品→场景 顺延；**prompt 内每次出现角色名都挂
  引用**，但严禁侵入台词内文；
- 台词语法 `用中文<副词>说道<台词>`；长台词"停顿一拍后继续用中文说道<…>"
  二段化；声画同出模型一次生成台词+口型+音效，语速要求写进 prompt（"人物台词
  语速调整偏慢"）。

## 二、连续性系统（跨型通用）

### 角色状态块（A 型八字段，顺序固定）

```text
【角色状态追踪】<角色>-位置：<相对参照，如"街道中心偏西（与上一镜相同位置）">。
<角色>-姿态：<站立/蜷缩/弓步…>。<角色>-动作状态：<说话中/说完话/被拍得一个趔趄…>。
<角色>-朝向：<面向X/面向东…>。<角色>-手部状态：<右手持剑前指，左手捏剑诀…>。
<角色>-持有物品：<无（继承）/佩剑（斧头可能背在身后）…>。
<角色>-情绪状态：<词+可加强度>。<角色>-伤势状态：<无伤/颈部轻微出血…>。
```

扩展位（按需）：`服装状态`（换装连续性）、`头部朝向`（与身体朝向分离时）。

规则：

- **覆盖场上所有角色，包括本镜不入画者**；交互动作双方状态都记（拍肩者记手部
  落点，被拍者记"被拍得一个趔趄"）；
- 状态继承显式标注：`（继承）`、`（与上一镜相同位置）`；
- 动作状态记**进程**：说话中→说完话——相邻镜以此咬合；
- 持有物品含画外推断（"斧头可能背在身后"），防止道具凭空消失。

### 情绪强度弧线

`情绪:<词> N/10` 是跨子镜的表演升压计：**有方向性弧线，拒绝全程恒值**——升压
为主，平台整理，回落合法（劝说方 4→5 稳定、被劝方 5→6→7 翻脸、崩溃后 7→4
泄力都是好弧线）。每镜变动 ±1~2 档。

### 空间连续

- 位置写**相对参照**（"病床右侧""右肩上"），不写绝对坐标；
- 场景资产用方位变体逐镜选用（`探视室（北）`/`篝火（近）`），正反打双方各绑
  各的背景资产防穿帮；
- 位移必须有过渡镜头，禁瞬移。

## 三、模型选型逻辑（一律泛称，不写产品名）

按本集主导戏型选"线"，同线内选最新代：

| 线 | 适用 |
|---|---|
| 声画同出全能线 | 15s 分镜组量产默认（多人对白+叙事） |
| 质感线 | 唯美/静场戏 |
| 动作线 | 打戏密集集 |
| 表演线（旧代单镜） | 4-8s 单镜表演戏、微动作特写 |
| 后处理线 | 口型修正、字幕擦除兜底 |

## 四、参数配置

| 参数 | 规则 |
|---|---|
| duration | 15s 主力（分镜组）；4-12s 按戏量（单人小反应 5-8s，大场面/信息戏 15s） |
| aspectRatio | 竖屏短剧 9:16；横屏剧集/动漫 16:9（发行形态决定，全剧恒定） |
| amount | 可控模型 =1，靠精准重投迭代；只有低可控旧模型才 3-5 条盲盒 |
| resolution | 草稿 480p 试跑 → 量产 720p → 交付 1080p+超分 |

运动幅度、特效等控制**全部写在 prompt 正文**，不依赖参数字段。

## 五、负面约束体系（防字幕/防串语言/防缺陷）

1. **头部禁令**（风格头后紧跟）：`画面不要出现任何文字，生成视频无BGM；`
2. **尾锁**：`【不出现任何文字字幕】`（最后一个子镜之后）
3. **语言锁**（多语/出海）：`角色必须严格按照剧本台词的原始语言说话。画面中
   不得渲染任何可见字幕。`
4. **模型缺陷补丁**（条件启用，仅目标模型确有该缺陷时）：防双胞胎（多同类角色
   戏，首尾各写一遍利用注意力两端）、防人物过大（"限制人在场景中的大小"）。
5. **后处理兜底**：量产经验证明单靠 prompt 禁令必然漏字幕，**先禁再擦双保险**。
6. **模型专属负面词表是条件规则**：某些写实视频模型明令禁用"瞳孔反光/如鹰隼般/
   指节发白/咬牙切齿/僵立+说话"类抽象与生理细节词，而同样的词在其他模型上是
   高质量判据——写前必须确认目标模型，两套规则不可混用（VID-10）。

## 六、决策规则

1. **大场面必拆**：元素并发数是重做成本的第一预测因子（"王座+群跪+手机特写"
   压进一条 15s 的真实重做比 10/15；拆三条低元素镜后全部 1-3 次过）。一个子镜
   内新元素 ≤2。
2. **台词密集镜单独成条**：台词戏与大动作戏不同条混装。
3. **反应特写铁律**：每 2-3 句台词后插对手纯反应特写 2-3 秒。
4. **台词长度**：一镜 <17 字（要求慢速时 <12 字）。
5. **重试必须带迭代**：每次重投改一个变量（拆元素/补状态锚定/换措辞），禁止
   同 prompt 抽卡。
6. **写实人脸最贵、3D 动漫最稳**：写实真人线预算重做比 ≈1.3-1.5，排期按此留量。

## 七、范例（合成改写）

### A 型：六件套 + 状态追踪（拔剑镜）

```text
真人电影风格,画面描述: 镜头转向修士甲，听到命令，他脸上非但没有紧张，反而咧开
一个兴奋好战的笑容。他右手猛地发力，"锵"一声清脆的剑鸣，长剑完全出鞘。他手臂
前伸，闪着寒光的剑尖稳稳指向前方的魔物。视觉重点：观众视线聚焦于修士甲拔剑的
动作和脸上兴奋的笑容。构图(Composition): 过肩镜头，从修士甲背后看向魔物。
景别(Shot Scale): 中景。机位(Camera Position): 轴线后侧机位。角度(Angle): 平视。
镜头类型(Lens Type): 标准镜头。光线(Light): 剑身反射的寒光打亮了他的脸。
【角色状态追踪】修士甲-位置：队首前方。修士甲-姿态：站立，弓步。修士甲-动作
状态：拔剑指向魔物。修士甲-朝向：面向魔物（西）。修士甲-手部状态：右手持剑
前指，左手捏剑诀。修士甲-持有物品：佩剑。修士甲-服装状态：道袍完整。修士甲-
情绪状态：兴奋，战意高昂。修士甲-伤势状态：无伤。
```

### A 型：连续三镜的状态咬合（说话中→说完话→新角色入画交互）

```text
镜1【角色状态追踪】修士甲-动作状态：说话中。…修士甲-情绪状态：痛快，兴奋。
镜2【角色状态追踪】修士甲-动作状态：说完话。…修士甲-情绪状态：自信，骄傲。
镜3（虎妖甲入画拍肩）【角色状态追踪】虎妖甲-位置：修士甲身旁。虎妖甲-动作状态：
大笑并拍打修士甲肩膀。虎妖甲-手部状态：右手拍在修士甲肩上，左手叉腰。虎妖甲-
持有物品：无（斧头可能背在身后）。修士甲-姿态：站立不稳。修士甲-动作状态：被拍
得一个趔趄。修士甲-手部状态：双手下意识抬起保持平衡。修士甲-情绪状态：无奈，
但带着笑意。
```

### B 型：四元组状态接续（收尾镜，情绪低值也要标）

```text
真人电影风格,画面不要出现任何文字，生成视频无BGM；
(空间:居所阳台（南）(@图片3) 阳台)(姿态:女主(@图片2)-靠在男主(@图片1)肩上;
男主(@图片1)-站立望远)(位置:男主-阳台栏杆右侧; 女主-靠在男主右肩上)
(情绪:男主-平静 2/10, 女主-幸福 2/10) 远景，镜头继续缓缓后拉并微微上升，两人
靠在一起的身影越来越小，阳台、房屋、周围的建筑逐渐进入画面。远处天空湛蓝如洗，
几朵白云悠然飘过，整个画面沐浴在温暖的金色阳光中，一切归于宁静。
【不出现任何文字字幕】
```

## 八、自检清单

1. 每个子镜开头有四元组/状态块吗？上镜终态=本镜起点吗？
2. 场上所有角色（含不入画）都在状态块里吗？交互双方都记了吗？
3. 有代词"他/她/它"吗？有比喻拟人吗？（改角色名、改物理成因）
4. 情绪分有方向性弧线吗？（拒绝全程恒值；回落合法）
5. 头部禁令+尾锁齐全吗？多语剧带语言锁了吗？
6. 单子镜新元素 ≤2 吗？大场面拆开了吗？
7. 台词 <17 字/镜、语速要求写了吗？每 2-3 句台词后有反应特写吗？
8. @图片引用齐全且未侵入台词吗？
9. 目标模型的专属负面词表核对过吗？
