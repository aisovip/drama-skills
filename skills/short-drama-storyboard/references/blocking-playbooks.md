# 条件分镜推演：竖屏、单房、证据与群体轴线

先使用 shot craft 的 coverage/purpose/geography 方法。只有命中下列场景条件时加载；它们是
思考路径，不是镜头数量模板。

## 1. 竖屏多人调度

竖屏不是把所有人排成上下两层。先画可通行平面，再决定纵向画幅如何表达权力：

- 用前/中/后景、门框、台阶、桌沿建立深度；
- 明确谁能接近证据、出口或权力座位；
- 头像高低只在空间真实且有意义时表达地位；
- 两人对话时仍保留第三人的监听、反应或阻挡位置；
- 出入方向和 eyeline 先连续，再用近景强化选择。

推演顺序：空间锚点与入口 → 每人的 agenda/筹码 → 群体 attention center → 关键动作
前后站位 → 必须 wide 保留的同时反应 → 只有失去信息时才切 insert/close。

失败征兆：每句台词一个头像 close-up；站位只为填满画面；背景人物在 cut 间换边；重要人物
一直被前景遮住却无人利用这种遮挡。

## 2. 单房对白

单房戏的运动来自策略、物件和注意，不来自无理由走动。先建立“压力几何”：

- 出口、座位、桌面/证物、电话/电梯声源；
- 谁先占据/控制哪个锚点；
- 谁能触碰、打开、藏起或拒绝某件物；
- 哪个声音能改变时间压力但不引入新人物。

每轮按以下链设计 coverage：

~~~text
话语/沉默策略 -> 对方如何接或拒绝 -> 物件/目光/空间发生什么 -> 谁暂时掌权
~~~

同一 two-shot 可以承载多轮，只在注意、解释或权力真的改变时切。Reaction 不必总是脸部：
可表现为不碰纸袋、把钥匙推过边界、手从门把移开、允许沉默持续。

误用：为了“画面丰富”让人物轮流起身、倒水、看窗。若动作不改变议程或证据条件，会削弱表演。

## 3. 证据揭示

先写 audience knowledge transition，再选镜头：

1. 证据在哪里、谁控制；
2. 揭示前观众能读到什么；
3. 是形状/状态/精确文字/关系才构成证据；
4. 谁先看见，谁看见对方已经看见；
5. 得知后哪个行动变了。

覆盖功能可以是 orientation、access、evidence view、receiver reaction、consequence，但不规定
固定顺序。若精确文字是证据，shot 绑定 source text policy 与本帧 treatment；不要用一闪而过
的 insert 假装观众能读完。若证据只是纹样/断角，禁止 prompt 临时造字。

## 4. 群体与轴线

把群体拆成有功能的 zone，而不是每人一个轴：

- 主行动者/对手的 working axis；
- 见证者或队列所在 zone；
- 入口/出口与权力锚点；
- 群体 attention 的方向变化。

轴线跨越可用人物同镜穿越、neutral bridge、新 wide 重建 geography，或创作者明确选择的
主观错乱。群体反应不需齐刷刷 close-up；选择会改变风险的代表反应，或用 wide 展示沉默、
退让、围拢、让路。

## 5. View 与边界演算

**SHT-09 · reviewed_invariant**：exact Location/View 的 orientation 与 visible anchors
必须匹配 shot 真正的 camera side。

Location 是整体地理，View 是一个有方向/时段/光态的可复用观察状态。镜头在门外朝内时不能
只因“仍是同一城门”就绑定门内朝外 View。选择 View 前逐项比对 camera side、可见 anchors、
orientation、time/weather/light；缺少合适 View 时向 assets 请求新 variant。

每个 cut 前后比较：

- position/facing/gaze；
- left/right hand 与 held prop；
- injury/Look/visible State；
- axis/screen direction；
- 门/灯/天气/文字状态；
- 谁知道什么（只引用 write source）。

Shot end 是 authority；keyframe 投影 start；motion 只实现区间。不能把本镜 action 的结果提前
写进 start keyframe，也不能在相邻两镜重复完整动作。若 SHOT-02 的 end 是“右手刚开始伸出”，
SHOT-03 才能完成取物；若 SHOT-02 已完成取物，SHOT-03 只能从“已持有”继续。

## 6. 规则分级

- structural_invariant：coverage、ArtifactRef、accepted bindings、start/end、相邻边界可解析。
- reviewed_invariant：切镜保留 source meaning，View 匹配摄影机侧，证据有可读时间和反应。
- craft_default：先建地理、按注意变化切、单房用策略/物件制造运动；可有理由覆盖。
- taste_option：镜头数量、景别、手持/固定、留白、反应方式由 visual direction 决定。
