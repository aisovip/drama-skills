# 合成正例：从剧本块到冻结关键帧

本例只演示推理链与 ArtifactRef，不是镜头数量答案。素材为全新合成。

## 剧本块

~~~md
## EP004-SC002 内 · 社区洗衣房 · 清晨

烘干机还在转。沈禾把一张写着“17”的取衣牌压在掌心，没有递给柜台后的蒋姨。

蒋姨：你不是来取衣服的。

[SFX] 烘干机停转。

沈禾摊开右手。取衣牌背面粘着一小片带血的蓝线头。
~~~

假设 index 已建立 H01（场景标题）、A01（持牌动作）、D01（判断）、P01（停机声）、
A02（摊手与蓝线头）。

## Coverage

| Block | Disposition | 理由 |
|---|---|---|
| H01 | covered SHOT-01 | 建立门、柜台、烘干机和双方位置 |
| A01 + D01 | covered SHOT-01 | 持牌不递与台词是同一策略对撞 |
| P01 | covered SHOT-02 | 声音改变注意并制造停顿 |
| A02 | covered SHOT-02, SHOT-03 | 动作 wide 保手位；detail 给证据；repeat 有新信息 |

没有“一块一镜”。A02 重复是因为第一次说明谁摊手，第二次才让观众读到蓝线头。

## SHOT-01：拒绝交牌

Purpose：建立蒋姨控制柜台、沈禾控制证物的关系，让台词成为判断而非说明。

- start：沈禾柜台外，右拳握牌；蒋姨柜台内；烘干机转；
- action：沈禾把拳压在台沿但不越过边界，蒋姨不伸手；
- end：手位不变，蒋姨已公开“你另有目的”；
- framing：纵向 medium two-shot，柜台横线分隔双方；
- camera：locked，让“不递”持续。

## SHOT-02：声音制造选择空间

Purpose：停机声让被机器掩盖的沉默显形，并把注意从两人脸上转到沈禾右手。

- start 继承 SHOT-01 end；
- SFX 精确引用 P01；
- 沈禾听见停机，先不看机器，而是决定摊开右手；
- end：右掌摊开，牌正面仍贴掌，背面朝蒋姨/观众，蓝线头存在但不要求读清；
- camera：从 locked two-shot 有动机地下移，终点仍保留蒋姨视线。

这不是“为了节奏推近”，而是 attention 从判断转到证据。

## SHOT-03：证据 detail

Purpose：让观众确认牌背的带血蓝线头，并保留蒋姨已经看见的关系。

- start 精确继承 SHOT-02 end；
- detail 只含右掌、牌背、蓝线头；背景保留蒋姨眼睛/视线的模糊位置；
- text policy：数字 17 在正面，本镜展示背面，因此不临时翻牌造可读文字；
- end 与 start 相同；信息变了，物理状态没变；
- locked detail；时长给观众识别颜色、血迹和附着关系。

“信息变化而物理状态不变”仍是有效 shot purpose。

## KEY-03：冻结瞬间

~~~text
社区洗衣房柜台外，沈禾摊开的右掌位于画面焦点；取衣牌背面朝上，
一小片带暗红血迹的蓝线头粘在牌背边缘。右手与牌完全静止，柜台横线
仍分隔双方，后景保留蒋姨已落在证物上的目光。清晨冷白顶光，转停的
烘干机只是空间锚点。画面不展示牌正面的“17”，不加入递交、翻牌、
推镜或表情变化过程。
~~~

静态测试：所有事实能同一时刻存在。摊开是 SHOT-02 motion，KEY-03 只写“已摊开”。

## Continuity handoff

| Field | SHOT-01 end | SHOT-02 start/end | SHOT-03 start |
|---|---|---|---|
| 沈禾右手 | 握牌 | 握牌 → 摊掌 | 摊掌 |
| 牌朝向 | 背面不可见 | 背面转向蒋姨 | 背面可见 |
| 蒋姨目光 | 沈禾脸 | 右手 | 牌背 |
| 烘干机 | 转 | 停 | 停 |
| 观众知识 | 她拒绝交牌 | 她决定展示 | 看到血迹蓝线头 |

Motion 只能实现表中箭头，不能让蒋姨夺牌、让牌正面突然朝镜头，或让机器重新启动。
