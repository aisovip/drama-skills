# 生产分镜语法惯例

真实短剧生产中分镜描述的通行语法，源自大规模生产数据的模式提炼，示例为合成
改写。方法论见 [shot-craft.md](shot-craft.md) 与 [keyframe-craft.md](keyframe-craft.md)；
本文档提供生产端的词表与节奏基准，属 `craft_default`/`taste_option` 级参考。

## 镜头时长基准

- 单镜头以 15s 为主流上限，4/8/10/12s 次之；一个 authored shot 内部再切
  2–5s 的时间片描述。
- 时间片写法：`【0-3s】景别，运镜，角度` + 表演 + （片尾）台词。显式时间片
  总和不得超过镜头时长（对应 VID-04 的同源纪律）。

```text
【0-3s】全景，平移运镜，正面角度。夜，外。她腰背挺直躺在藤椅上，左手托举
高脚杯，杯身稳如磐石；右手指尖缓慢滑动屏幕，每页停顿半秒。
【3-6s】近景，缓慢推进。手腕匀速画圈摇杯，嘴角勾起不超过 1 毫米的弧度。
【6-10s】特写，固定镜头。笑意瞬间敛去，拇指长按语音键，指节发白。
台词：她（冷笑）：我被赶出门的时候，有谁替我讲过话？
```

## 词表

| 维度 | 生产常用词 |
|---|---|
| 景别 | 远景、全景、中景、中近景、近景、特写、大特写、空镜头 |
| 运镜 | 固定镜头、缓慢推进、平移、横移跟拍、环绕、后拉、俯冲下降、聚焦虚化、手持跟拍 |
| 角度 | 正面、侧面 30°/45°、过肩、低角度仰拍、微仰视、高空航拍 |
| 构图 | 前中远景递进、对角线构图、物理高低差、前景背面 3/4 侧 + 后景正面 3/4 侧 |

词表是 `taste_option`（SHT-07）；但同一时间区间的运镜互斥、轴线一致属结构纪律。

## 时间片内的因果顺序

每个时间片按"内部状态 → 外显微动作 → 台词"排列一个因果：先写触发（听到
埋怨），再写身体信号（眼尾收紧、握杯指印），最后落台词。避免把多个表演目标
塞进同一片——那是拆片或拆镜的信号（SHT-03）。

## 空间与轴线纪律

- 过肩、对峙、两人物理高低差要写明前后景各自的朝向与 3/4 侧；
- 全程遵守 180° 轴线，越轴需要显式 transition 或新 View；
- 同一地点按朝向/分区拆分可复用视图（"走廊（北）""办公室（东）"式的
  View 命名——对应资产层的 Location/View 模型，见 AST-03）。

## 反应镜头预算（SHT-11）

生产数据显示"对白覆盖了、后果反应缺失"是高频缺陷（rubric 常见发现）。基准：
关键信息落地后，至少一个反应镜头承接权力/关系变化；群像震惊用"远景全场
凝固 + 近景单人失态"两级递进，不用同景别复读。
