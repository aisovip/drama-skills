# 生产质量门：高频缺陷、环节判据与生产纪律

提炼自大规模量产语料的返工记录与数千条人工退回指令，示例均为合成改写。审查
方法见 [review-method.md](review-method.md)；本文档提供生产端验证过的预防清单
与可操作判据（REV-08 的完整展开）。

**质量的第一性原理：每个环节的产出都是下游的输入——上游省的每一分力，下游
都要加倍偿还。**

## 一、人工退回的五大高频缺陷（预防性满足）

1. **数量失控**：分镜数不符合目标。→ 生成前先定数量预算并自检。
2. **表演/空镜单薄**（最高频）：真实退回指令原型——"增加大量空镜头，细腻化
   人物表演，丰富角色的神态和表情，物品景色特写，台词语速调整偏慢"。→ 每镜
   必有微动态与神态描写，穿插空镜。
3. **漏台词/漏剧情**：→ 生成后对照剧本逐句核对台词覆盖。
4. **位置漂移**：→ 状态块/站位声明逐镜续写，绝不省略。
5. **格式残留**：秒数残留、前缀不统一。→ 交付前做格式检查。

## 二、各环节质量门（好 vs 平庸的可操作判据）

### 剧本门

- 对峙戏升级 ≥3 次且每次换新实物；弱势方 ≥2 个非语言反应拍；收尾落在败方/
  旁观者。
- 主角在打戏中付出可见代价；空间/资源单调递减；每 3 拍出现新变量。
- 好开场在第 2 拍抛出异常；平庸开场用 10+ 段铺背景且无一个可拍摄动作。

### 分镜门

- 删掉台词后能看见 4 秒连续运动（平庸样本删台词只剩静态姿势）。
- 一滴汗有四个阶段 vs "轻松地说话"一个姿态词完事。
- 每镜有叙事动机句；无动机运镜的项目整体质量档次更低。
- 镜头纲要是完整节拍摘要（人审索引），不是敷衍两个字。

### 资产门

- 每个视觉细节能归因身份（因果链检验）。
- 资产只写不变量；场景光/情绪进白底定妆图=返工。
- 物品颜色+材质+工艺三元组。

### 成片提示词门

- 状态显式接续：每镜开头把上一镜终态写进起点；位置用相对参照。凭空开镜是
  重做比 >3 的高发区。
- **元素并发数是重做成本的第一预测因子**：高并发大场面压进一条 15s 的真实
  重做比 10/15；拆成低元素镜后 1-3 次过。大场面必拆。

## 三、生产纪律（量产验证过的规律）

1. 拆镜密度跟情绪走：爽点/反转/打脸 15s 内 6-7 镜；情感戏 3-4 镜。
2. 时长跟戏量走：单人小反应 5-8s，多人大场面/信息戏 15s。
3. 模型可控性越强，单次出量越小：可控模型单条+精准重投；不可控模型才盲盒挑片。
4. 分辨率省钱阶梯：草稿 480p 试跑 → 量产 720p → 交付才 1080p+超分。
5. 防字幕双保险：prompt 头尾双禁令 + 后处理擦除兜底——单靠禁令必然漏。
6. 定点手术改图：一句改动 + 显式冻结其余——只说改什么不说保什么会连锁漂移。
7. 重试必须带迭代：同 prompt 连续重提是纯抽卡；每次改一个变量。
8. 一次拆完、流水推进：量产剧一次拆全季、流水推进+停靠点人审；零敲碎打的
   单集试水一半死在半途。
9. 剧本在视频期仍可回改——发现分镜/成片问题时允许回到剧本层修，不硬扛
   （走 owner 修订，不绕过所有权）。

## 四、换算速查

| 换算 | 数值 |
|---|---|
| 剧本→成片 | 980 字 ≈ 2 分钟 |
| 一集 | ≈ 8 条 15s 分镜组（或 18-27 条 4s 单镜）≈ 2 分钟 |
| 拍→镜 | 1 拍 ≈ 1.5 镜 |
| 一集拍数 | 15±3 拍 |
| 长篇资产量 | 80 集剧 ≈ 80+ 角色 / 120+ 场景 / 70 物品 |

## 五、通用反模式墙（各环节红线汇总）

- 剧本：小说直贴、心理叙述、三行骨架、同质拍循环、格式污染。
- 分镜：旁白切片、空壳镜、无动机运镜、资产名/引用标记泄漏、广告混入。
- 资产：定妆图带场景光、一句话资产、无语义命名、名实不一。
- 提示词：凭空开镜（无状态接续）、大场面不拆镜、负面约束堆砌淹没内容、依赖
  模型不出字幕。
- 指令：把内容塞进指令字段、空泛形容词规则、不区分模型条件混用规则。

本文数值为量产校准基准（`craft_default`）；reviewer 引用具体判据给出修改意见，
不空评"不够好"（对应 REV-05），也不把基准偏离直接当 blocker——除非它坐实了
某条 structural/reviewed invariant。
