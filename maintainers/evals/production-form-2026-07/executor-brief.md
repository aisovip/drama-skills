# Anonymous executor brief

Each executor received a clean context, one anonymous installed skill tree, and
`fixture.md`. It was told to use that tree as its only craft guidance, avoid the
opposite arm, repository history, source research, expected results, browsing,
and all media operations, then write a compact but complete text handoff.

The requested output was a director note, essential asset/image-prompt choices,
one shot and frozen keyframe intention, a boundary-preserving motion intention,
and an evidence-versus-taste review checklist for both synthetic scenes. Each
executor also had to preserve unresolved choices and avoid vendor fields, model
names, fixed durations, and new story facts.

The output paths were isolated. Executors were not told whether their anonymous
tree was baseline or candidate.
